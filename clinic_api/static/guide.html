Setup & Run

# 1. Clone the repository
git clone https://github.com/paidadharshitha/clinic-booking-api.git
cd clinic-booking-api

# 2. Create an environment
python3 -m venv .venv
source .venv/bin/activate

# 3. Install dependencies
pip install -r requirements-dev.txt
pip install --no-deps -e .

# 4. Start the server
uvicorn clinic_api.main:app --reload

# 5. Run the tests
pytest

Validation & Error Responses

  • Required fields, valid names and email addresses
  • Valid date/time with an explicit timezone
  • End time after start time
  • Future, active and available slots
  • Clinic, slot and booking must exist
  • Helpful errors with proper status codes 404 · 409 · 422 · 503

Concurrency Handling

Database transactions protect each booking. Even when two requests arrive at the same time, only one can succeed. 

# SQLite write transaction
BEGIN IMMEDIATE;
# Check slot, then insert booking
INSERT INTO bookings (...);
COMMIT;

# Database safety net
UNIQUE (slot_id)
WHERE status = 'confirmed'

Independent connections. Serialized writes. A partial unique index as the final guard.
